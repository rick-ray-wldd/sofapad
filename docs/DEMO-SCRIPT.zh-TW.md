# SofaPad 示範影片腳本

[English](DEMO-SCRIPT.md) | **繁體中文**

這份腳本配合示範場 `demo/playground.html`，錄一支 SofaPad 4.3 的示範影片。關卡順序和示範場一樣：

1 觸控板 → 2 打字 → 3 送出後自動清空 → 4 游標板 → 5 快捷鍵 → 6 縮放與桌面 → 7 4.3 新排版 → 總表

示範場每一關都會自己判斷有沒有做到，做到就亮綠勾；整關做完會出現「✓ 完成：○○」和「下一關 →」。下一關要自己用手機的觸控板點，不會自動跳。

---

## 打開示範場

在 repo 的資料夾裡：

```bash
open demo/playground.html
```

安裝包（`SofaPad-4.3.0-macOS.zip`）裡也有一份：解壓縮後雙擊資料夾裡的 `playground.html`。

- 用 Mac 的瀏覽器打開（Safari 或 Chrome 都可以）。不用網路，也不用開伺服器。
- **語言**：示範場預設英文。按右上角的「中文」，或在網址最後加上 `?lang=zh`，就換成中文；這份腳本寫的是中文版畫面上的字。可以和其他設定一起用，例如 `?lang=zh&rec=1`。
  手機網頁跟著手機的語言（4.4）：錄中文版時，手機設成中文，或在 ⚙︎ →「語言」選「中文」，手機上的字才會和這份腳本一樣。
- **錄影模式**：按右上角「錄影模式」，或在網址列的網址最後加上 `?rec=1`，例如 `file:///…/demo/playground.html?rec=1`。錄影模式會：
  - 藏起每關的小字說明和頁尾；
  - 放大標題、綠勾和「完成」橫幅；
  - 左上角顯示「SofaPad 示範 · 第 N 關」。
- **直接跳到某一關**：網址最後加 `#stage=3`（1–7，或 `#stage=summary` 總表）；也可以點上方的 1–7。
- 「重來」會清掉全部進度，回到第 1 關。已經有進度時要按兩下（第一下會變成「確定重來？」）。
- 示範場不收集任何資料：不連網路、不存檔，關掉就清空。
- 視窗至少 1280×800。最好用全螢幕（⌃⌘F），瀏覽器縮放 100%（⌘0）。

## 手機上的 4.3 長這樣

旁白和畫面說明以這個為準。

### 直拿

- 文字框大約是手機寬度的一半。
- 右半邊是「◀ 游標 ▶」（游標板）和 ⏎（Enter）。⏎ 預設固定在游標板右邊。
  - 游標板：按住約 0.3 秒（手機輕震一下）再拖，Mac 的文字游標就用方向鍵跟著走；快速甩一下，一次跳一個字詞。
- 下面是按鍵列：
  - 最前面是「即時／整段」和「⌘ 快捷鍵」；
  - 再來是「⇧ 選取」，現在是普通的鍵，可以移動、可以拿掉；
  - 然後是 esc、tab、⌫、方向鍵、⌘ ⌥ ⌃ ⇧、space、⌦；
  - 最後是「✎ 編輯」。
- 「✎ 編輯」打開編輯器，有三個分頁「輸入列｜按鍵列｜橫拿側欄」：
  - 按住 ≡ 拖曳，調整順序；
  - ✕ 拿掉；
  - 點下面清單裡的項目，加進來；
  - 「全部恢復預設」（三列一起回到預設）。
- 就算拿掉了「⇧ 選取」，拖游標板的時候另一根手指點一下，一樣是選取。

### 橫拿

- 一邊是可以收合的側欄。右手用的時候側欄在左邊；「左手模式」時在右邊。
- 側欄裡：
  - 最上面一條細列：連線狀態、鍵盤、拖曳鎖定「鎖」、設定 ⚙、收合 ‹；
  - 文字框＋游標板＋⏎；
  - 下面是一格一格的按鍵：按鍵列的鍵，加上只有橫拿才有的快捷鍵，例如 ⌘C ⌘V ⌘X ⌘Z ⌘A ⌘Tab、Mission Control、⌃← ⌃→。
- 另一邊是全高的觸控板。
- 收合側欄就是全螢幕觸控板；浮動按鈕裡的 › 可以再打開側欄。

### 其他要示範的功能

- **即時模式**：邊打字邊出現在 Mac 上；注音要選好字才送出；聽寫不會疊字。
- **整段模式＋送出**：先在手機上打好、改好，按「送出」一次送過去。
- **送出後自動清空**（4.2 開始）：一段打完（點觸控板、按鍵、做手勢、用游標板、收起鍵盤），輸入框就清空，舊字不會再送一次。
- **手勢**：
  - 兩指點一下＝右鍵；兩指上下滑＝捲動；兩指張開／捏合＝⌘＝／⌘−；
  - 三指往左／往右滑＝切換桌面；往上／往下＝Mission Control／App Exposé；
  - 長按再拖＝拖曳；「鎖」＝拖曳鎖定；
  - 右邊的細長條＝單手捲動。
- **快捷鍵面板**：包括截圖到剪貼簿 ⌃⇧⌘4。

## 錄影設定

兩種拍法，選一種。

**A. 一台相機從肩膀後面拍**：手機和 Mac 螢幕同時入鏡。看得到手指，最直覺。

- 鏡頭對焦在手機上；Mac 螢幕亮度調到不過曝。
- 注意反光；直接拍螢幕可能有摩爾紋，可以稍微斜一點或拉遠一點。

**B. 分割畫面**（畫面最清楚）：

- **Mac**：⌘⇧5 →「錄製整個螢幕」或「錄製選取的部分」（框住瀏覽器）→「錄製」。結束：按選單列的停止鍵。
- **iPhone**：控制中心 →「螢幕錄影」。
- **合成**：用剪輯軟體左右並排，例如左邊 Mac、右邊手機。
- **對齊兩段影片**：
  - 開頭拍一下手（兩邊都有錄到聲音時）；或
  - 開頭用手機的觸控板點示範場的「重來」：Mac 畫面會黑一下、出現「開始」，手機那段同一刻是點觸控板。
- iPhone 螢幕錄影看不到手指。長按、兩指、三指這些動作，可以另外用相機拍手，或在旁白說出來。
- 轉成橫拿時，手機那段的畫面也會轉；剪輯時記得轉正或換版面。

## 錄影前清單

- [ ] Mac 開「勿擾模式」，關掉通知。
- [ ] iPhone 開「勿擾模式」，切成靜音。
- [ ] 桌面乾淨：只開示範場；關掉私人視窗、聊天、信箱；收起桌面上的檔案。
- [ ] 準備第二個桌面（Mission Control 最上面的「＋」），三指切桌面才有地方去。
- [ ] 系統設定 → 鍵盤 → 鍵盤快速鍵… → Mission Control：勾選「Mission Control」「應用程式視窗」「移到左邊的空間」「移到右邊的空間」。
- [ ] 手機亮度調高；自動鎖定調長（設定 → 螢幕顯示與亮度 → 自動鎖定）。
- [ ] 兩台的電量都夠，或接著電。
- [ ] 手機和 Mac 連同一個 Wi-Fi。
- [ ] Mac 已解鎖（鎖定時手機的輸入會暫停）。
- [ ] SofaPad 已經有「輔助使用」權限；手機左上角是綠點。
- [ ] 手機和 Mac 都是 4.3.0（手機 ⚙︎ 最上面一行）。
- [ ] 建議 Mac 用英文（ABC）輸入法，中文用手機的注音打。
- [ ] 截圖那關會用到剪貼簿：框選的範圍不要包到私人內容。
- [ ] 示範場按「重來」，從第 1 關開始；要的話打開「錄影模式」。

## 錄影精簡版（`?video=1`）

想錄一支短一點的影片（例如戴 Vision Pro 螢幕錄影）時用。網址最後加上 `?video=1`（中文再加 `&lang=zh`，錄影模式加 `&rec=1`）。安裝包裡的 `playground-video.html` 打開就是精簡版。

- 只有 5 關，畫面上編號 1–5：**1 觸控板 → 2 打字 → 3 快捷鍵 → 4 縮放與桌面 → 5 4.3 新排版**，最後是總表（只算這 5 關的項目）。「送出後自動清空」和「游標板」兩關不在精簡版。
- **第 2 關打字**只有兩格：
  - ① 即時模式：用 iPhone 英文鍵盤打「I can type from the sofa with my phone」，可以一個字一個字用滑的（滑動輸入）。自動加的空格、開頭大寫、句尾的空格或句點都沒關係；滑錯的字會標紅，下面寫第幾個字打成什麼、應該是什麼，刪掉重滑就好。
  - ② 鍵盤 🎤 聽寫：說一句話，停一下（中文或英文都可以），顯示「沒有疊字 ✓」。
- 其他關卡的做法和完整版一樣（場景 1、5、6、7）。
- `#stage=` 用的是完整版的關卡號碼（1、2、5、6、7）；也可以直接點上方的 1–5。

## 錄影時的小提醒

- 三指切桌面沒反應：先確定有第二個桌面，而且「錄影前清單」裡的快速鍵都開了。
- 瀏覽器整頁放大了：按 ⌘0 恢復。示範場一樣會算「放大／縮小」有做到。
- 某一關卡住：點上方的號碼跳過，或之後再回來；「重來」會清掉全部進度。
- 第 3 關出現紅字「有殘留」：按「清空重試」，這一關重新來。
- ⌃⇧⌘4 之後游標變成十字：用長按拖曳框選；不要了按 esc。
- 錄影模式下看不到小字說明；要看說明時先關掉錄影模式。
