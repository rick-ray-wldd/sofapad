# SofaPad 4.4.0

Use your iPhone as the Mac's keyboard and trackpad — from the sofa, or with Vision Pro and Mac Virtual Display. The
phone opens a page served by a small menu-bar app on the Mac; nothing goes through a cloud.

## What's new

- **The phone page in English and Chinese.** It opens in your phone's language (Chinese if the phone is set to
  Chinese, English otherwise). ⚙︎ → **Language** (Auto, English, 中文) switches it at once: no reload, the connection
  stays, and text in the box stays where it is. Every text is translated: the key row, the text row, the landscape
  panel, the row editor, the shortcut panel and editor, settings, pairing, messages and the screen-reader labels.
- **Light and dark theme.** ⚙︎ → **Theme**: System (the default: follows the phone's light or dark appearance, also
  while the page is open), Light or Dark. The page is drawn in the right theme from the first frame, and the browser
  bar follows. Text and key labels meet WCAG AA contrast in both themes.
- Both choices are remembered on the phone.

Nothing else changed: layouts, gestures, typing, dictation, the box emptying after each piece, the cursor pad and the
rows work as in 4.3.0. In the dark theme the filled blue (Send, the selected tab, drag lock on, an armed ⌘) is a
little deeper than in 4.3.0, for contrast.

## Download and install

`SofaPad-4.4.0-macOS.zip` — macOS 13 or later, **Apple silicon (arm64) only**. On an Intel Mac, build it yourself.
Check it with `shasum -a 256 -c SofaPad-4.4.0-macOS.zip.sha256`.

**Not signed with an Apple Developer ID and not notarized** (ad-hoc signature only): macOS blocks it the first time.
Open it with System Settings > Privacy & Security > **Open Anyway**. Full steps, in English and Chinese:
[`docs/INSTALL.md`](../INSTALL.md). Or build it yourself (`./tools/build-app.sh`, README step 1A): a self-built app is
not blocked.

Then grant **Accessibility** to SofaPad (System Settings > Privacy & Security > Accessibility) and scan the QR code
from the menu bar with the iPhone. After updating, reload the page on the phone (close and reopen the Home Screen app).

The zip also has the demo page (`playground.html`, `playground-video.html`) and the recording scripts; their English
versions now quote the phone's English labels.

## Known limits

- On a Home Screen app, the iPhone's status bar (clock, battery) takes a new theme the next time the app opens.
- Plain http on the local network, no encryption: use it at home or on a network you trust.
- The automated tests run in a simulated phone page (headless Chrome, iPhone sizes) against the Mac app in dry-run
  mode. 4.4.0 has not been tried on a real iPhone before this package.

# SofaPad 4.4.0（繁體中文）

把 iPhone 當成 Mac 的鍵盤和觸控板：在沙發上用，或戴 Vision Pro 用 Mac 虛擬顯示器時用。手機打開 Mac 選單列小程式提供的網頁，不經過任何雲端。

## 這一版

- **手機網頁有中文和英文**：跟著手機的語言打開（手機是中文就是中文，其他是英文）。⚙︎ →「**語言**」（自動、English、中文）馬上切換：不用重新整理、不會斷線，輸入框裡的字也還在。所有的字都有兩種語言：按鍵列、輸入列、橫拿側欄、按鍵編輯、快捷鍵面板和自訂快捷鍵、設定、配對、提示訊息，連讀螢幕用的標籤也是。
- **淺色和深色主題**：⚙︎ →「**主題**」：系統（預設，跟著手機的淺色／深色外觀，網頁開著時也會跟著變）、淺色、深色。網頁從第一個畫面就是對的主題，瀏覽器的工具列顏色也會跟著。兩種主題的文字和按鍵字都符合 WCAG AA 對比。
- 兩個選擇都記在這支手機上。

其他都沒有變：排版、手勢、打字、聽寫、每段送出後清空輸入框、游標板和各列按鍵，都和 4.3.0 一樣。深色主題裡實心的藍色（送出、選中的分頁、拖曳鎖定中、按下的 ⌘）比 4.3.0 深一點，為了對比。

## 下載和安裝

`SofaPad-4.4.0-macOS.zip`：macOS 13 以上，**只支援 Apple 晶片（arm64）**；Intel Mac 請自己 build。可以用 `shasum -a 256 -c SofaPad-4.4.0-macOS.zip.sha256` 核對。

**沒有 Apple Developer ID 簽章，也沒有公證**（只有臨時簽章 ad-hoc）：第一次打開會被 macOS 擋下，到「系統設定 → 隱私權與安全性」按「**強制打開**」。完整步驟（中英）：[`docs/INSTALL.md`](../INSTALL.md)。也可以自己 build（`./tools/build-app.sh`，README 第 1 步 A），自己 build 的不會被擋。

接著在「系統設定 → 隱私權與安全性 → 輔助使用」打開 SofaPad，再用 iPhone 掃選單列的 QR code。更新後，手機的頁面要重新整理（主畫面 App 關掉重開）。

zip 裡也有示範場（`playground.html`、`playground-video.html`）和錄影腳本；英文版現在引用的是手機上的英文按鈕名稱。

## 已知限制

- 加到主畫面的 App，iPhone 狀態列（時間、電量）的顏色要下次打開 App 才換成新主題。
- 區網內是一般的 http，沒有加密：請在家裡或信任的網路使用。
- 自動測試是在模擬的手機頁面（headless Chrome，iPhone 尺寸）對 dry-run 的 Mac App 跑的。4.4.0 打包前還沒有在真的 iPhone 上試過。
