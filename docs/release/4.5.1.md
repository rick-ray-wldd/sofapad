# SofaPad 4.5.1

Use your iPhone as the Mac's keyboard and trackpad — from the sofa, or with Vision Pro and Mac Virtual Display. The
phone opens a page served by a small menu-bar app on the Mac; nothing goes through a cloud.

## What's new

- **Signed with an Apple Developer ID and notarized by Apple.** This is the first SofaPad with a Developer ID
  signature that Apple's notary service has checked. A downloaded copy opens with a double-click: macOS asks once
  whether to open an app from the internet, and you click **Open**. No more System Settings > Privacy & Security >
  **Open Anyway**.
- **The Accessibility permission: once more, then it stays.** macOS now knows SofaPad by its developer instead of by
  the code of each version. After this update, give the permission one last time (see below); later updates keep it.

Nothing else changed: SofaPad works as in 4.5.0, and it updates itself the same way, with the same EdDSA key.

## Download and install

`SofaPad-4.5.1-macOS.zip` — macOS 13 or later, **Apple silicon (arm64) only**. On an Intel Mac, build it yourself.
Check it with `shasum -a 256 -c SofaPad-4.5.1-macOS.zip.sha256`.

**New install**: unzip it, drag `SofaPad.app` into Applications and double-click it. macOS asks whether you want to
open an app downloaded from the internet: click **Open**. Then turn on the Accessibility permission. Full steps, in
English and Chinese: [`docs/INSTALL.md`](../INSTALL.md).

**From 4.5.0**: SofaPad offers 4.5.1 by itself (or ⌨︎🖱 → 檢查更新…, Check for Updates): **Install Update**, then
**Install and Relaunch**. Then give the Accessibility permission one last time: System Settings > Privacy & Security >
Accessibility, select SofaPad, click **−**, then click **+** and add `/Applications/SofaPad.app`. The phone says when
the permission is missing.

**From 4.4 or earlier**: quit SofaPad, put this one in its place in Applications, open it, and give it the
Accessibility permission again the same way.

## Known limits

- An app you build yourself (`./tools/build-app.sh`) is still signed ad-hoc for your Mac: it isn't blocked, but it
  needs the Accessibility permission again after each rebuild. Only the release zip has the Developer ID signature.
- Plain http on the local network, no encryption: use it at home or on a network you trust.
- The automated tests run in a simulated phone page (headless Chrome, iPhone sizes) against the Mac app in dry-run
  mode. The app and the phone page are the same as in 4.5.0; only the signature is new.

# SofaPad 4.5.1（繁體中文）

把 iPhone 當成 Mac 的鍵盤和觸控板：在沙發上用，或戴 Vision Pro 用 Mac 虛擬顯示器時用。手機打開 Mac 選單列小程式提供的網頁，不經過任何雲端。

## 這一版

- **第一次用 Apple Developer ID 簽章，並經過 Apple 公證。** 下載後雙擊就能打開：macOS 只會問一次要不要打開從網路下載的 App，按「**打開**」就好。不用再到「系統設定 → 隱私權與安全性」按「**強制打開**」。
- **「輔助使用」權限：最後再開一次，之後就不會再跑掉。** macOS 現在是用開發者認 SofaPad，不再用每個版本的程式碼。這次更新後要再開一次權限（做法在下面），之後的更新都會保留。

其他都沒有變：用起來和 4.5.0 一樣，自己更新的方式和 EdDSA 金鑰也一樣。

## 下載和安裝

`SofaPad-4.5.1-macOS.zip`：macOS 13 以上，**只支援 Apple 晶片（arm64）**；Intel Mac 請自己 build。可以用 `shasum -a 256 -c SofaPad-4.5.1-macOS.zip.sha256` 核對。

**第一次安裝**：解壓縮，把 `SofaPad.app` 拖到「應用程式」，再雙擊打開。macOS 問要不要打開從網路下載的 App 時，按「**打開**」。接著打開「輔助使用」權限。完整步驟（中英）：[`docs/INSTALL.md`](../INSTALL.md)。

**從 4.5.0 更新**：SofaPad 會自己提示 4.5.1（或點 ⌨︎🖱 →「檢查更新…」），按「**安裝更新項目**」，再按「**安裝並重新啟動**」。之後最後一次重新開「輔助使用」權限：系統設定 → 隱私權與安全性 → 輔助使用，選 SofaPad 按「**－**」移除，再按「**＋**」加入 `/應用程式/SofaPad.app`。權限沒開時，手機會告訴你。

**從 4.4 或更早的版本**：結束 SofaPad，把這一版放到「應用程式」取代舊的，打開它，再用同樣的方法開「輔助使用」權限。

## 已知限制

- 自己 build 的 App（`./tools/build-app.sh`）還是只有這台 Mac 的臨時簽章（ad-hoc）：不會被擋，但每次重新 build 後，「輔助使用」權限都要再開一次。只有發布的 zip 有 Developer ID 簽章。
- 區網內是一般的 http，沒有加密：請在家裡或信任的網路使用。
- 自動測試是在模擬的手機頁面（headless Chrome，iPhone 尺寸）對 dry-run 的 Mac App 跑的。App 和手機網頁都和 4.5.0 一樣，只有簽章是新的。
