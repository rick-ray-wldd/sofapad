# SofaPad 4.2.0

Use your iPhone as the Mac's keyboard and trackpad — from the sofa, or with Vision Pro and Mac Virtual Display. The
phone opens a page served by a small menu-bar app on the Mac; nothing goes through a cloud.

## What's new

- **No more old text in the box.** If you ended a piece without Enter — clicked a Mac app's Send button with the
  trackpad, tapped elsewhere, switched apps — the words stayed in the phone's box, and the next edit could send part of
  them again into another window. Now any click, key, gesture, the cursor pad or closing the keyboard ends the piece:
  the rest goes to the Mac, the box empties.
- **No more getting stuck after Zhuyin was interrupted**, and "Send" in batch mode no longer sends half-composed
  bopomofo.
- **Cursor pad**: hold "◀ 游標 ▶" next to the text box, then drag to move the Mac's text cursor with the arrow keys;
  select with Shift ("⇧ 選取" on the key row, or a second finger); flick to jump a word.

Still in 4.2: the refusal page for phones outside the local network and the "allow Tailscale devices" switch (4.1).

## Download and install

`SofaPad-4.2.0-macOS.zip` — macOS 13 or later, **Apple silicon (arm64) only**. On an Intel Mac, build it yourself.
Check it with `shasum -a 256 -c SofaPad-4.2.0-macOS.zip.sha256`.

**Not signed with an Apple Developer ID and not notarized** (ad-hoc signature only): macOS blocks it the first time.
Open it with System Settings > Privacy & Security > **Open Anyway**. Full steps, in English and Chinese:
[`docs/INSTALL.md`](../INSTALL.md). Or build it yourself (`./tools/build-app.sh`, README step 1A): a self-built app is
not blocked.

Then grant **Accessibility** to SofaPad (System Settings > Privacy & Security > Accessibility) and scan the QR code
from the menu bar with the iPhone.

## Known limits

- Plain http on the local network, no encryption: use it at home or on a network you trust.
- The cursor pad and the text-box fix were tested in a simulated phone page (headless Chrome) against the Mac app, with
  unit tests on both sides, and with real typing into TextEdit on a Mac; the feel on a real iPhone is still to be
  confirmed.

# SofaPad 4.2.0（繁體中文）

把 iPhone 當成 Mac 的鍵盤和觸控板：在沙發上用，或戴 Vision Pro 用 Mac 虛擬顯示器時用。手機打開 Mac 選單列小程式提供的網頁，不經過任何雲端。

## 這一版

- **輸入框不會再留著舊字**：沒按 Enter 就結束（用觸控板點 Mac App 的「傳送」、點到別處、切 App），之前字會留在手機的輸入框，下一次編輯可能把一部分舊字再送到別的視窗。現在點擊、按鍵、手勢、游標板或收起鍵盤都算「這段打完了」：剩下的字先送到 Mac，輸入框清空。
- **注音選字到一半被打斷不會再卡住**；整段模式在選字中按「送出」也不會送出注音符號。
- **游標板**：按住輸入框右邊的「◀ 游標 ▶」再拖，用方向鍵移動 Mac 上的文字游標；按按鍵列的「⇧ 選取」或第二根手指點一下改成 Shift 選取；快速甩一下一次跳一個字詞。

4.1 的「不在區網的說明頁」和「允許 Tailscale 裝置」開關都還在。

## 下載和安裝

`SofaPad-4.2.0-macOS.zip`：macOS 13 以上，**只支援 Apple 晶片（arm64）**；Intel Mac 請自己 build。可以用 `shasum -a 256 -c SofaPad-4.2.0-macOS.zip.sha256` 核對。

**沒有 Apple Developer ID 簽章，也沒有公證**（只有臨時簽章 ad-hoc）：第一次打開會被 macOS 擋下，到「系統設定 → 隱私權與安全性」按「**強制打開**」。完整步驟（中英）：[`docs/INSTALL.md`](../INSTALL.md)。也可以自己 build（`./tools/build-app.sh`，README 第 1 步 A），自己 build 的不會被擋。

接著在「系統設定 → 隱私權與安全性 → 輔助使用」打開 SofaPad，再用 iPhone 掃選單列的 QR code。

## 已知限制

- 區網內用一般 http，沒有加密：請在家裡或可信任的網路使用。
- 游標板和輸入框修正是用模擬的手機網頁（headless Chrome）對 Mac App、兩邊的單元測試，以及在 Mac 的「文字編輯」實際打字驗證；真的 iPhone 上的手感還要確認。
